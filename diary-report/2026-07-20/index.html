🔥 今日精选（5 个最值得关注的）

1. MCP 变现平台 — XPack-MCP-Marketplace

  • 一句话：全球首个开源 MCP 变现平台，快速创建和售卖自己的 MCP 服务
  • 为什么值得关注：MCP 生态正在爆发（Cursor、Claude、VSCode 全系支持），但缺少收费基础设施。这个项目填补了”开发者做 MCP 服务怎么赚钱”的空白。搭配 Cloudflare Workers 或 Edge Functions 就能跑
  • Star/热度：⭐ 164 | 📈 新项目持续增长
  • 个人开发者切入点：做一个垂直场景的 MCP Server（比如 Figma 转代码、SEO 分析、竞品监控），通过这个平台售卖，月费 $10-49/用户

2. velobase-harness — AI 原型秒变付费 SaaS

  • 一句话：让 AI 开发者把原型变成付费 SaaS 的开源基础设施
  • 为什么值得关注：解决了”AI prototype 很多但不知道怎么收费”的核心痛点。内置 Stripe 集成员、用量追踪、订阅管理。个人开发者用此框架可以几天内把一个 AI demo 变成月收入
  • Star/热度：⭐ 580 | 📈 刚上架
  • 个人开发者切入点：用这个框架封装一个 AI 写作助手、Stable Diffusion 定制服务等，直接上架收月费

3. Chalie — AI 同事（不是员工）

  • 一句话：把自己产品化——AI 作为你的同事而不是下属
  • 为什么值得关注：Show HN 热门。定位精准——不是取代人，而是增强人。个人开发者可以用这个方向切入企业服务：做”AI 团队扩展”产品，每个用户按席位收费
  • Star/热度：HN 热门讨论
  • 个人开发者切入点：用这个框架做垂直行业版（如 AI 设计师助手、AI 数据分析师），$20-50/座位/月

4. Bolt Slides — 用 AI Agent 生成交互式演示稿

  • 一句话：使用任何 AI Agent 创建令人惊叹的交互式演示文稿
  • 为什么值得关注：Bolt 团队出品（此前 Bolt.new 已经验证了 AI coding 的市场）。演示文稿是个大市场（$100亿+），但 AI 做 PPT 的产品大多质量不行。Bolt Slides 用 agent 实现了真正的交互式、可部署的演示
  • Star/热度：⭐ 443 | 新项目
  • 个人开发者切入点：可以包装成 SaaS：bolt-slides + custom template marketplace，对标 Gamma.app 但更技术化

5. Claude YouTube Skill — Claude Code 的 YT 创作者工具

  • 一句话：Claude Code skill 为 YouTube 创作者提供频道审计、SEO、脚本优化的全套工具
  • 为什么值得关注：Claude Code 的 skills 生态正在形成，这是一个很好的变现模式——做 Claude Code skill 然后在 marketplace 售卖。目标用户（YouTuber）付费意愿强
  • Star/热度：⭐ 252
  • 个人开发者切入点：做细分领域的 Claude Code/Kimi Code skill：SEO audit、内容营销、电商运营等，每个 skill 定价 $9-29

  • 多个项目同时出现：codeburn（⭐8758，追踪 31 种 AI 工具 token 消耗）、Backlog.md（⭐6233，人类-AI 协作管理）、LoopGain（用控制理论防止 agent 死循环）

趋势 2：Vibe Coding 商业化困境与破局

  • V2EX 上 “Vibe Coding 副业四个月：成本超出收益” 引发 32 条讨论。核心矛盾：AI 降低了开发门槛但 API 费用吃掉了利润
  • 对个人开发者的启示：真正的机会不在 AI 写代码本身，而在于：1) 帮助别人优化 AI 使用成本的工具；2) 找到 API 成本几乎为零的场景（如纯本地推理、或者一次开发多次售卖的模板）

趋势 3：Agent 经济层（Agent Economy Layer）

  • 对个人开发者的启示：为 agent 做基础设施——MCP server、agent 支付接口、agent-to-human 服务的中间层，这是 2026 年的 “掘金卖铲子” 机会

🎯 行动建议

基于今天的发现，个人开发者可以考虑的 2 个具体行动方向。

方向一：做 MCP Server + 平台变现

MCP 生态正在快速成为 AI agent 的”App Store”。个人开发者只需：

  1. 找到一个垂直场景（SEO 分析/社交媒体运营/代码审查/设计规范检查）
  2. 做一个 MCP Server（几天的工作量）
  3. 通过 XPack-MCP-Marketplace 或自建 landing page 售卖
  4. 月费 $9-49/用户

方向二：Agent 使用成本追踪 SaaS

多个项目都在指向同一个痛点——“AI agent 好用但太贵且不知道钱花哪了”。 做一个轻量 SaaS：

  • 接入 Claude Code/Cursor/GitHub Copilot 的 API
  • 展示 token 使用、费用、项目分布
  • 对个人免费（limited），团队版 $19/月
  • 目标用户：正在用 AI coding 的中小团队
