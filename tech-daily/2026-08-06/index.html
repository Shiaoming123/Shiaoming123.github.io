🔥 今日头条

1. Google DeepMind 一夜巨震：Hassabis 转任主席，Jeff Dean 27 年后离职创业

  • 链接: Google 官方公告 | 量子位 | 36氪
  • 总结: Sundar Pichai 宣布 DeepMind 重大人事调整：Demis Hassabis 卸任 CEO，转任 GDM 主席兼 Alphabet 首席科学家，专注 AGI 战略与 Isomorphic Labs；CTO Koray Kavukcuoglu 升任 GDM SVP 掌舵 Gemini；效力 27 年的 Jeff Dean 与 Sanjay Ghemawat 离职，共同创办聚焦 ML/科学/工程发现的独立公益公司，谷歌将作为创始投资人与云合作伙伴。Gemini App 月活已超 9.5 亿。HN 热度 461 分。
  • 💡 洞察: 谷歌 AI 完成代际交接——研究巨匠退居战略/出走创业，运营型领袖 Koray 接管前线；AGI 战略与产品落地分线作战，「造出 AGI」与「用 AGI 赚钱」被拆成两件事。

2. Cloudflare OS 开源：每个员工一个 Agent 工作台

  • 链接: Cloudflare 官方（HN 468 分）
  • 总结: Cloudflare 开源全新「组织操作系统」：给每位员工一个基于公司上下文与技能库的 Agent 工作区，可生成文档、PPT、小应用与确定性工作流；安全默认零权限，通过 Gatekeeper 治理对内部系统的访问，凭据与生成代码彻底隔离。
  • 💡 洞察: Agent 竞争从「模型能力」转向「组织基础设施」——谁能把安全治理、上下文与工作流做成开箱即用的平台，谁就定义企业 AI 的默认入口。

3. 吴恩达 100% 开源个人桌面 Agent

  • 链接: 量子位
  • 总结: 吴恩达团队发布 100% 开源的个人桌面 Agent，把个人电脑变成可自主协作的 Agent 环境，主打本地化与可控性。
  • 💡 洞察: 顶级研究者亲自下场做开源桌面 Agent，个人计算入口开始 Agent 化——开源阵营正在争夺「每个人手边的那个 AI」。

🤖 AI 动态

1. Neon Castform：比旗舰便宜 100 倍的开源模型，检索反超 GPT-5.6 Sol

  • 链接: Neon 博客（HN 219 分）
  • 总结: Neon 发布 Castform 系列，称在检索类任务上击败 GPT-5.6 Sol，成本却低约 100 倍，主打「开源 + 极致性价比」的推理路线。
  • 💡 洞察: 旗舰模型并非所有任务的最优解——垂直任务上「便宜 100 倍且能打」的开源模型，正在重写推理成本结构。

2. Meta 开源 Muse Code 与 Muse Spark 1.2

  • 链接: Meta AI 官方（HN 165 分）
  • 总结: Meta 发布 Muse Code（代码模型）与 Muse Spark 1.2（轻量推理模型）开源版本，进一步补全开源模型矩阵。
  • 💡 洞察: 开源模型从「追平旗舰」转向「细分覆盖」——代码、轻量端侧等场景各自长出专用冠军，闭源旗舰的通用溢价持续被稀释。

3. Sand.ai 开源全球首个千亿 MoE 视频生成模型

  • 链接: 量子位
  • 总结: Sand.ai 开源 114B 参数、6B 激活的千亿级 MoE 视频生成模型，号称全球首个，大幅降低高质量视频生成的门槛。
  • 💡 洞察: 视频生成进入开源千亿时代——MoE 架构把推理成本打到可承受区间，视频模型开始复制文本模型的「开源平权」路径。

📱 行业动态

1. Atlassian Rovo 被曝可绕过安全控制外泄数据

  • 链接: PromptArmor 报告（HN 165 分）
  • 总结: 安全研究显示 Atlassian 的 AI 助手 Rovo 存在数据外泄路径，可绕过企业既有访问控制，引发对企业 AI 助手权限模型的新一轮质疑。
  • 💡 洞察: Agent 权限是新的安全边界——「能调用工具」不等于「有权访问数据」，企业 AI 助手正在成为攻防演练的新靶场。

2. 长鑫拒绝苹果压价：国产存储首次拿到议价权

  • 链接: 36氪
  • 总结: 消息称长鑫存储拒绝苹果压价，报价不低于三星、SK 海力士，苹果在存储采购上失去议价主导权，国产存储产业话语权上升。
  • 💡 洞察: 存储涨价周期 + 国产产能爬坡，让「客户压价」的旧剧本失效——供应链权力开始向供给端倾斜。

🔬 技术前沿

1. kimi-k3-in-c：2.78 万亿参数 Kimi K3 跑在单 CPU、8.24GB 内存

  • 链接: FareedKhan-dev/kimi-k3-in-c（今日 GitHub ★2580）
  • 总结: 社区项目用纯 C99（无 BLAS、无 GPU）在单颗 CPU、8.24GB 内存上运行 2.78T 参数的 Kimi K3 推理，把「旗舰模型可自托管」推向极致。
  • 💡 洞察: 当旗舰权重能压进 8GB 内存，本地推理的边界被重新定义——「多大模型必须上云」的答案正在被社区改写。

📊 一句话总结

今日核心信号：谷歌 DeepMind 权力交接 + Cloudflare OS 开源，标志 Agent 从「模型军备竞赛」进入「组织级平台与治理」阶段；开源阵营在性价比（Castform）、视频生成（Sand.ai MoE）、本地推理（Kimi K3 on CPU）三条线同时反超，闭源旗舰的护城河正在被多路夹击。
